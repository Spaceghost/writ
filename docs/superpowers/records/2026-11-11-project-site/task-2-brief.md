# Task 2: public project website

Build a static site under `utils/site/`. Lead with "Data carries its terms" and
the restricted report becoming an internal summary. Explain independent
verification and final authority rechecking, with clearly labeled illustration
states and direct links to the executable examples. Show current platform
evidence and open integration work without treating models as host qualification.

Use a restrained editorial layout, warm paper, dark ink, a precise green accent,
and a custom diagram drawn in HTML/CSS/SVG. Provide install/copy commands,
evidence/roadmap links and contributor guidance. All essential content works
without JavaScript. Support small screens, keyboard focus and reduced motion.

Publish a reproducible static Worker package on only `/writ` and `/writ/*`.
Constrain methods and asset paths; no backend policy decisions, accounts,
external scripts or runtime secrets. Browser-check the page and test route
boundaries before deployment. Retain screenshots outside the source tree.
