Shim review 1 of 9: what the file claims to be, and how the component starts

This first pass reads the file's own description of itself, its compile-time bounds, and the component entry. Some Genode vocabulary first. A session is a connection one component opens to a service another component (or the kernel-side core) provides; the parent (here, init) routes each session request according to its configuration. A capability is an unforgeable reference to an object in another component: holding it lets you call that object, nothing more. A quota is the RAM and capability count a component was given by its parent; opening a session donates part of it. The Pd_session (protection domain) is the component's own session to core for its address space, RAM, and caps. An Entrypoint is a thread that receives RPCs and signals for objects it manages. The shim is linked into each Bend program, replaces libc's mmap/munmap/mprotect, and supplies the C functions behind the Genode.log/now/sleep/take/put effects. Lines 1-239 are one long comment; read 1-74 now and keep the rest for later pages. Lines 438-486 hold the shim's state for the life of the process: Kept<T> never runs a destructor, so nothing is torn down under mapped memory at exit (INVENTORY.md:360-367).
