# Synthetic handoff model

A worker report followed by a repeated handoff must not create a second protected delivery. `HostHandoff.bend` models only trusted-monitor preflight sequencing and delegates actual admission to the unchanged `HostPrimitives.admit_worker`; it is not a Windows IPC adapter or security qualification. Its 37 synthetic `HH-*` checks are included in the 2,102-check core suite. Native facts and current local/core state are trusted inputs; a revision value cannot independently prove that an OS fact was freshly measured.

The model's terminal `Aborted` state records local fail-stop without changing the HostPrimitives authority state or emitting an effect. Stale local revision preserves the state; the trusted stream adapter must separately poison/retire a failed stream. Existing `admit_worker` checks its own revision, resolves the current session/reference, configured profile and control/inventory facts, and emits its original `DeliverInputs` only on acceptance. This wrapper does not perform a DataOS/Backplane final commit, prove publication or revalidate unmodeled budget/epoch/scope at commit; those remain with existing gates. Atomic installation and ordering against revocation/restart, route completeness, peer authentication, native cleanup, externally visible diagnostic channels and continuous Windows enforcement remain unimplemented host obligations. See [portable-host traceability](../../../../openspec/traceability/portable-host-contract.md) and the [handoff inventory](handoff-inventory-and-model-design.md).

No strict worker gate, native Windows path, production law, policy release decision or prior native evidence changed. Windows byte-worker confinement remains incomplete.

The clean current-master extraction was checked on Linux with Bend 2.0.39 and Node 26.10.0: both produced 2,102 passing checks and byte-identical output (SHA-256 `0fb92a34387ff14ea30bb97bb09fc8a79585b058a6057c6acdd54692f6dcf45c`). Existing `PROOF.bend` reported `ALL PROOFS CHECK` through Bend's checker; no new law was added and no Lean kernel verdict or GPU execution is claimed. A native CPU compilation is in progress from the separate experimental worktree; its result requires a separate record tied to that actual source and verified Bend-source equivalence before it can be attributed to this extraction.
