01 / The model

Permission has to
survive the journey.

Writ follows the relationship between an input, a proposed computation, and its destination. The final write must still satisfy the terms of its origins.

01

Carry the origins forward.

Copies, summaries, and transformations retain the source’s confidentiality, integrity, operation, and payment obligations.

Provenance contract ↗
02

Check the proposal independently.

A solver proposes an assignment. The Bend verifier checks the original constraints, independently of the solver’s working graph.

Verification contract ↗
03

Recheck before release.

Paired read and write grants must agree. At commit, Writ resolves the live capability and checks current authority before returning a scoped write intent.

02 / Evidence & direction

Ambitious by design.
Specific about the evidence.

Writ is an executable security library and protocol model. Turning it into a complete protected-data environment requires further native integration and qualification.

THE CORE

Runnable models.
Inspectable results.

The library includes tests, worked examples, and selected formal laws. Recorded CPU, GPU, and independent kernel results each have their own source and scope.

Read the verification record ↗
THE BOUNDARY

A returned write intent still needs an enforcing host to perform the effect and persist state. A passing model test does not establish worker confinement or crash-safe publication.

The host’s obligations ↗

Windows

First product target

Mounted reads, caller denial, and revocation pass. The strict confinement gate remains failed: direct byte-worker channel probes are incomplete.

Evidence ↗

Genode

Capability reference

Linux

Native host target

Real FUSE reads, actor denials, revocation, and cleanup have recorded canary evidence. Complete protected-host qualification remains open.

A native storage foundation

Meet WritFS.

Private Btrfs snapshots. ZFS filesystem and block-volume clones. Bend authorizes the operation; the native filesystem performs it, preserving the output policy in a verified private-stage receipt.

Whole-dataset presentation, device export, durable publication, and complete worker confinement remain separate work.
