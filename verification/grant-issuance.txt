## Not exercised

- Transport authentication: every `from: Principal` is a synthetic fixture.
  No Genode route, Linux peer credential or Windows token is verified here.
- Signatures: no approval carried off-host is cryptographically verified;
  Bend checks no signature.
- Durable storage: the issuer state lives only in the test run. Nothing is
  persisted, recovered or rolled back.
- Concurrent hosts: there is no serialization of installs between hosts or
  processes. Races are modeled by the revision check only (AB-006 is a host
  obligation).
- Per-use projection rebuilding by a host: the tests rebuild projections at
  each use themselves; no host does.
- Any native host: no Genode, Unikraft, Linux, Windows or rclone binding runs
  issuance. The native-backend run above is the library corpus compiled
  for the CPU, not a host binding.
- GPU: no device code ran; this CPU run is not a GPU test.
