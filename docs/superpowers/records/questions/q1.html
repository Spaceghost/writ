Which Genode path is the long-term monitor?

There are now two ways Writ runs on Genode. Spaceghost's native-hosts canary runs the generated JavaScript core under QuickJS on base-hw and mounts a WritFS File_system service. Our lanes run the generated C under Bend's own runtime, now on both base-linux and base-hw, with the Writ_channel session (buckets and a signal per client, records decided by Bend).
