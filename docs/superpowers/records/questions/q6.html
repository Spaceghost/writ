The buckets runtime: brainstorm with Spaceghost first, or draft from his message?

Spaceghost described "a datacentric Rust of sorts, not a programming language, but buckets and code for the buckets as a runtime built to be cache-friendly and speedy when typed". The brief for him lists the questions a design would need to settle (unit of typing, who owns a bucket's code and where it runs, queries over buckets versus views, what is Bend policy versus runtime mechanism).
