## Native arity layout (AuditTests.bend)

The first native build of this tree failed with `Error: an arity over 247`
(`bend Tests.bend` and the JavaScript build do not show it). The native
backend limits a def or continuation to 247 words, and records are unboxed,
so the words of every record live in one def count. Seven `AE.Recorded`
values in one list literal already exceed it. The sites were two fixture lists
(`interleaved`, 8 records; `projected_denials`, 10 events) and five checks
that hold several commit or admission fixtures in one def. The fix keeps
every check, name and order: the four multi-conjunct checks are split into one
named Bool def per conjunct, the one single-conjunct check into one def per
operand, and the two lists are consed onto a `_rest` def holding the
remainder. Inlining the new defs and folding the lists back gives the earlier
tokens exactly; the 285 check names are identical before and after; the
JavaScript output is byte-identical to the run before the change (the SHA-256
above).

## Laws added (LAWS.bend, proved in PROOF.bend)

- audit_admission_event_ignores_diagnostic: for every plan, context, labels, subject, two caller tokens, two diagnostics and event id, the admission events are equal. Limits: says nothing about which fields are sensitive (the event policy's job).
- audit_commit_event_ignores_diagnostic: the commit event equals the projection of the facade's result without any diagnostic and with any other caller token. Limits: the token may change the decision, and reaches the event only through it.
- audit_admit_returns_library_decision: audited_admit returns exactly Transfer.admit's decision, so a denied transfer stays denied with its reason. Limits: no durability or append.
- audit_commit_returns_library_result: audited_commit returns exactly the facade's result, so a rejected commit keeps the caller's session and ledger. Limits: no durability or append.
- audit_failed_influence_withholds: one influence that does not flow to the sink label makes influences_flow False at any position. Limits: does not claim releasable is the only route to a sink.
- audit_outcome_never_lowers_policy: the recorded admission policy is admission_policy(plan, context, labels, subject) for every token, diagnostic and event id, hence every decision. Limits: does not claim the influence list is complete.
- audit_invisible_event_unobservable: inserting an event the caller may not see anywhere in the log leaves view unchanged. Limits: does not claim respond reads the log only through view (structure, tested), or anything about timing.
- audit_stale_query_refused: respond at the successor revision is the public refusal. Limits: successor revision only; host serialization of installs is not claimed.
- audit_refusal_is_constant: whenever the revision is current and some query gate fails, respond returns exactly Refused{Unavailable{}}. Limits: does not claim the gate list is complete (tests pin each gate).
- audit_ungranted_export_emits_nothing: with no grant naming exactly this exporter, owner, sink and channel, transmit emits nothing. Limits: does not claim the grant registry is correct or that a host sends nothing outside transmit.
- audit_revoked_export_emits_nothing: when the grant found is revoked, transmit emits nothing. Limits: does not claim revoke_export sets the flag (tested), or anything about expiry or epoch (tested).
- audit_export_outside_stream_unobservable: inserting an event outside the owner's stream leaves export_log_view unchanged. Limits: does not claim transmit reads the log only through export_log_view (structure, tested).

Tested, not proved: the canonical encoding and decoding (U32 words are not
inductive), the scope rule, the influence derivation, the stream rule and the
query and export gate pins.

## Not exercised

Durability (no append, durable or otherwise), crash injection and recovery,
history verification (authenticated predecessors, trusted head, idempotency),
the required-event queue, denial-append failure, any native host (Genode,
Unikraft, Linux, Windows, rclone), transport authentication of `from` and of
the caller subject, and the GPU. The timing, scheduling and traffic-volume
channels and the one-bit label-table channel are stated in docs/AUDIT.md and
are not closed.
