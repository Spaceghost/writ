# Writ rules in the desktop drive

Connect a team bucket and a public delivery bucket. Browse real files in the
Writ file list without downloading their contents, then open an ordinary local
file when needed. Copy a team document
to another approved destination and retain its origin and restrictions. Try
the public destination and see the transfer refused, with the reason in the
app's activity view. Inspect or restore an earlier version without discarding
its policy. These operations must change real S3-compatible storage.

Preview.3 supplies a Windows tray app and S3 folder sync, while Linux still
demonstrates one local public file. These do not yet present managed copies,
retained origins and policy-preserving restores through the same control UI
on both platforms. Remote shell placeholders remain separate integration work.

This change adds a desktop control interface and a common S3-compatible storage
adapter, shared Bend decisions, durable provenance/version receipts and native
folder integration. The intended account is the authenticated local owner.
Managed transfer rules do not claim to confine arbitrary desktop applications
after an authorized plaintext export. Proposed private matching, declassification,
payments and remote computation are not represented as working features.
