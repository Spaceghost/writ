## Equivalent mutants

- **P14** (drop the grant lifetime from the projected approval bound, leaving `Nat.min(until, offer valid_until)`). The projection is built only while `selection_current` holds, which includes the eligibility gate Outlives (`I.lifetime_within(offer valid_until, grant valid_until)`, offer ≤ grant) on the same grant record `grant_for` returns. So `min(offer, grant) = offer` whenever the bound is computed. The grant term is kept as defense in depth (it cannot widen the bound) and costs nothing.
- **P18** (an origin with no covering approval is projected anyway, at the bound). The arm is reached only when `covering_until` returns None for a listed origin. The projection runs only while `selection_current` holds, whose last eligibility gate is `origins_approved` over the same lookup (`T.required_origins(request plan, snapshot transfer)`; the offer plan equals the request plan by `plan_is_request`), the same stored approvals, the same provider, profile, issuer and `now`, and the same `stored_covers` predicate. So every listed origin has a covering approval and the None arm is unreachable. It is kept so that the helper fails closed if called outside `negotiation_context`.
- **T10** (the NoSelection arm of `trial_gates` holds). `submit_evidence` reaches the gate list only when `selected_provider_is` is True, which requires a selection; and `current_gates` precedes `trial_gates` in the same list and denies NotSelected on NoSelection (C6, killed through `selection_current` directly). The arm exists for totality only.
